# 砚芽 · 玄境｜前端蓝图 v0.1

更新：2026-10-26

## 产品一句话

一座随着陪伴、收藏与记忆而缓慢生长的灵境浮岛。以东方园林和古建筑承载空间，用星象、月相和西式神秘器具点亮细节；功能依然服务于真实对话。

## 视觉世界

### 外观
- 墨绿深海、青苹果绿、月银、雾粉；不使用大片奶油黄色。
- 浮空岛屿悬在云海，中央为岛心楼阁，远处可见天文仪、林木与签庭。
- 轻量 SVG + CSS 首版，后续可升级为精细插画或交互场景素材。
- 白昼与夜间分离的完整色板，不出现未适配的白色抽屉和固定颜色控件。
- 动画只是点缀；自动遵从系统 `prefers-reduced-motion`。

## 第一阶段：可操作的壳

已在 Seed 01 实现：
- 六处场景入口、响应式快捷栏、场景抽屉。
- 可手动切换昼夜；初次进入根据设备时间判断。
- 本机保存的离线聊天**界面预览**（不能调用 AI）。
- 本机保存的星阁手记、每日固定灵签、灵圃生长演示。
- 不读写旧 `aevren-xy` 的存储键。

待做：
- 完整桌面/手机交互与视觉验收。
- 收藏、聊天、书房和 MCP 的数据适配层。
- 完整主题令牌和文件模块化。
- WebView 2.0 与新应用包名。

## 第二阶段：有记忆的岛

- 事件日志 `island_events`，包含可撤销/去重的事件 ID、发生时间、事件类型、关联数据。
- 统一 `island_state`，状态由时间/节气、用户偏好和**主动保存**的事件派生，不暗中分析聊天内容。
- 星阁由数据索引产生星点；同一记忆在搜索、列表、星图都可以打开。
- 成长效果遵循可解释、可关闭、可回滚原则，不采用强制连续签到。

## 第三阶段：有生活的岛

- 离线优先，资源预缓存和更新版本提示。
- 昼夜、二十四节气、小雨、萤火、星轨各自有性能分级。
- 新旧数据迁移：独立备份 → 选择文件 → 只读预览 → 确认导入 → 验证结果。
- 接入独立 Android WebView 壳，`applicationId` 必须与旧版 `com.aevren.xy` 不同。

## 必须守住的交互约束

- 聊天是第一优先，不因为岛景多一层操作而变难打开。
- 重要功能仍可从快捷栏一步抵达。
- 设置 / 模型 / MCP 能折叠，删除等不可恢复操作要二次确认。
- 不为了迁移世界书而强制重构成酒馆；保留旧版书房的使用方式。
- 气泡尖角只属于整条消息，不在每个段落重复绘制。
- 深浅主题影响所有控件，包含弹窗、复选框、输入框和书房。
- 可见动画都应支持减少运动偏好；主界面保持流畅，避免长时间阻挡入口。

## 发布方式

第一阶段保留无构建步骤的静态网站，GitHub Actions 在 `main` 推送时发布根目录至 GitHub Pages。需要在仓库设置中的 Pages 将 Source 设为 GitHub Actions（具体是否已启用以设置页为准）。

WebView 壳以后加载新仓对应的 Pages URL。只要原生壳不变，修改 HTML/CSS/JS 并部署后，下一次打开即可获取网页新版；修改 Kotlin、权限、启动画面等才需要新 APK。
