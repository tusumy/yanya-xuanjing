# 砚芽 · 玄境 / Yanya Xuanjing

> 一座随着陪伴与记忆缓慢生长的岛。

这是砚芽的**独立前端重构实验仓**。旧版砚屿 `tusumy/aevren-xy` 保持原状，避免在新架构尚未稳定时损坏日常使用的聊天、书房、API 与 MCP。

## 核心设定

- **东方灵境为骨**：山、海、灵圃、藏书阁、节气、签文。
- **西式神秘学为光**：星图、月相、塔罗、天文仪与银色星轨。
- **陪伴为核心**：岛屿不替代聊天；岛上的建筑只是通往功能的空间入口。
- **日积月累的变化**：时间、季节、收藏、纪念、主动保存的记忆，让岛屿呈现不同状态。
- **美观不妨碍效率**：所有主要入口可直接访问；动画可降低或关闭。

## 当前阶段：v0.3 · 天地玄盘

本仓采用无构建依赖的静态原型（HTML/CSS/JS），方便通过 GitHub Pages 查看，之后再根据稳定性决定是否引入组件化构建工具。

已实现（Seed 01 + Seed 02）：
- 默认太极八卦星盘首页；一键切换回浮岛旧景，建筑入口保持可用
- 太极 → 两仪 → 四象 → 八卦 → 十六 → 三十二 → 六十四的交互衍化；八卦可通向岛内模块
- 六十四卦支持上下卦自由组合，依据文王卦序显示卦名、卦符与六爻；十六、三十二仅作为组合过渡层
- 可操作的浮岛首页，点击建筑进入模块
- 时间氛围切换，白昼 / 月夜手动覆盖
- 岛心（聊天 UI 演示）、星阁（浏览器本地收藏）、签庭（每日灵签）、藏书楼与天机台的入口
- 响应式、深浅主题、减少动画偏好
- 暂不接入实际聊天 API、账户、云同步或 Android 原生桥接

## 开发原则

1. 新旧项目**不共用存储键或 Android applicationId**。新原型使用 `yanya.xuanjing.*` 命名空间。
2. 新版本不可在没有迁移策略的情况下覆盖旧砚屿的数据；导入流程要支持备份与预览。
3. 数据优先留在本机；绝不在页面源码和仓库里保存 API Key。
4. 若后续使用 Android WebView 壳，可像旧版砚屿一样加载线上静态前端，前端更新不强制重装 APK；原生权限和桥接修改仍需重新发版。
5. 抽签、塔罗和星象作为自我表达与娱乐体验，不制造现实结果保证。

## 运行

直接打开 `index.html` 即可（推荐浏览器/静态网站），也可将根目录部署为 GitHub Pages。首次使用无需安装 Node.js。

详细概念见 [设计蓝图](docs/blueprint.md)。


## Seed 03 · 天地玄盘

根据手机端反馈，将演示型八卦布局改成可交互的沉浸式玄盘：
- 撤掉页面顶部的「太极／两仪／四象／八卦／十六／三十二／六十四」说明按钮与大号教学标题，保留只占一行的七点衍化进度。
- 主视觉是发光太极、八方卦符、64 道刻度、星屑、同心星轨与半透明青玉质感；触碰太极演进，左右箭头回退/前进，空白轨道区域可左右滑动。
- 乾兑离震巽坎艮坤仍保留准确卦位和可点击功能入口；六十四卦仍能选择上下卦、看到卦符与对应文王卦序。
- 切换「浮岛」可回到上一版岛景，不丢已保存的星阁、灵签或聊天预览数据。
- 移动端优化按键、布局；支持系统减少动画与省流量设置。
- 本阶段**只更新前端**；尚未接入真实聊天、真实占卜 API 或 Android 原生功能。

当前网站部署：GitHub Actions 发布成功后，使用 GitHub Pages 访问；如配置了自定义域名，需要 DNS 验证与 HTTPS 证书独立完成。

## 首页太极阵说明

- 默认显示八卦，点击顶部七个层级按钮或中央太极可逐步推演。
- 点击八卦环的符号查看其属性，再通过下方入口前往对应的功能区。
- 十六/三十二层通过上一组/下一组浏览四爻、五爻组合；六十四层通过上卦、下卦选择生成卦象。
- 经典句为“易有太极，是生两仪，两仪生四象，四象生八卦”。十六与三十二不被宣称为传统独立卦名。
- 当前更新仅涉及 HTML、CSS 和 JavaScript；尚未接入真实 AI 对话和 Android 安装包。
