# 砚芽 · 玄境 / Yanya Xuanjing

> 一座随着陪伴与记忆缓慢生长的岛。

这是砚芽的**独立前端重构实验仓**。旧版砚屿 `tusumy/aevren-xy` 保持原状，避免在新架构尚未稳定时损坏日常使用的聊天、书房、API 与 MCP。

## 核心设定

- **东方灵境为骨**：山、海、灵圃、藏书阁、节气、签文。
- **西式神秘学为光**：星图、月相、塔罗、天文仪与银色星轨。
- **陪伴为核心**：岛屿不替代聊天；岛上的建筑只是通往功能的空间入口。
- **日积月累的变化**：时间、季节、收藏、纪念、主动保存的记忆，让岛屿呈现不同状态。
- **美观不妨碍效率**：所有主要入口可直接访问；动画可降低或关闭。

## 当前阶段：v0.24 · 对话、书房与网页通话

本仓采用无构建依赖的静态原型（HTML/CSS/JS），方便通过 GitHub Pages 查看，之后再根据稳定性决定是否引入组件化构建工具。

已实现（Seed 01 + Seed 02）：
- 默认太极八卦星盘首页；一键切换回浮岛旧景，建筑入口保持可用
- 太极 → 两仪 → 四象 → 八卦 → 十六 → 三十二 → 六十四的交互衍化；八卦可通向岛内模块
- 六十四卦支持上下卦自由组合，依据文王卦序显示卦名、卦符与六爻；十六、三十二仅作为组合过渡层
- 可操作的浮岛首页，点击建筑进入模块
- 时间氛围切换，白昼 / 月夜手动覆盖
- 岛心（聊天 UI 演示）、星阁（浏览器本地收藏）、签庭（每日灵签）、藏书楼与天机台的入口
- 响应式、深浅主题、减少动画偏好
- 已接入 OpenAI 兼容聊天 API、多接口与模型管理、角色书房和网页语音通话；账户、云同步与 Android 原生桥接尚未接入

## 开发原则

1. 新旧项目**不共用存储键或 Android applicationId**。新原型使用 `yanya.xuanjing.*` 命名空间。
2. 新版本不可在没有迁移策略的情况下覆盖旧砚屿的数据；导入流程要支持备份与预览。
3. 数据优先留在本机；绝不在页面源码和仓库里保存 API Key。
4. 若后续使用 Android WebView 壳，可像旧版砚屿一样加载线上静态前端，前端更新不强制重装 APK；原生权限和桥接修改仍需重新发版。
5. 抽签、塔罗和星象作为自我表达与娱乐体验，不制造现实结果保证。

## 运行

直接打开 `index.html` 即可（推荐浏览器/静态网站），也可将根目录部署为 GitHub Pages。首次使用无需安装 Node.js。

详细概念见 [设计蓝图](docs/blueprint.md)。

## 首页太极阵说明

- 默认显示八卦，点击顶部七个层级按钮或中央太极可逐步推演。
- 点击八卦环的符号查看其属性，再通过下方入口前往对应的功能区。
- 十六/三十二层通过上一组/下一组浏览四爻、五爻组合；六十四层通过上卦、下卦选择生成卦象。
- 经典句为“易有太极，是生两仪，两仪生四象，四象生八卦”。十六与三十二不被宣称为传统独立卦名。
- 当前更新仅涉及 HTML、CSS 和 JavaScript；尚未接入真实 AI 对话和 Android 安装包。

## Seed 23 · 网页语音与通话

从旧砚屿 `aevren-xy` 的语音/通话流程移植浏览器适配版：
- 岛心新增通话、语音输入和语音设置；AI 消息可单独朗读。
- 通话使用当前接口、角色和世界书，支持字幕、按键识别、自动识别、静音、停止朗读与挂断。
- 通话消息保存在当前对话；挂断时保存时间与时长，随聊天备份导入导出。通话不会覆盖输入框草稿。
- 语言可选普通话、粤语和英语，朗读可选择设备声音与语速。识别依赖浏览器 Web Speech API，部分设备服务需联网；不支持时保留文字输入。
- 当前只使用系统朗读；MCP/ElevenLabs 音色、录音转写、安卓来电通知及后台接听尚未迁移，不会自动启用付费语音服务。
- 语音配置使用独立 `yanya.xuanjing.voice.v1`，不读写旧砚屿数据。

验证：JavaScript 语法检查、模拟通话收发/朗读完成/挂断清理/记录/无识别能力回退检查通过。执行环境无法启动浏览器，尚未完成实际手机麦克风、扬声器及布局验收。

## Seed 24 · MCP、消息操作与旧版备份迁移

- MCP 管理：添加、编辑、启停、删除、连接与工具目录；Streamable HTTP 初始化、会话标识、协议版本协商及分页工具发现。支持 JSON 与 SSE，收到匹配响应后结束流读取，避免长连接一直挂起。Token 只留在 sessionStorage。
- 聊天工具：已启用并连接过的 MCP 工具可由模型调用，执行前展示服务、名称与参数；最多 4 轮，支持停止。工具调用不自动重试，避免写操作重复执行。启用工具时使用非流式模型回复。
- 语音：可选择支持 `text_to_speech` 的 MCP，配置 Voice ID、Model ID 和语音标签；通话与消息朗读共用设置。支持 HTTPS 音频链接与 MCP 音频内容。服务调用可能消耗服务商额度。
- 消息：编辑、删除、收藏到星阁、最后一条回复重新生成；历史记录可搜索和改名。
- 角色：每段对话可以独立指定角色；新对话开场、文字聊天与通话均使用该角色设定和世界书。
- 数据：导出砚芽当前数据，分项恢复；旧版 `AevrenXYBackup` 支持预览后合并聊天文字、角色、世界书、默认开场与记忆。保留导入前快照，支持撤销；写入失败尝试回滚。仅操作砚芽自己的存储键。
- 迁移限制：当前聊天容量 36 段，每段最近 120 条文字，每条 12000 字；角色最多 100 个，角色设定与世界书各最多 12000 字，记忆最多 150 条。以现有内容优先，重复 ID 跳过。旧版图片附件、群聊成员、分支、备选开场、章节、条件触发规则、HTML 显示规则、密钥与账号设置尚未迁移，预览界面明确提示。

验证命令，在仓库根目录执行：

```sh
node tests/chat-integration.cjs
node tests/mcp-data.cjs
node tests/voice.cjs
```

以上为模拟环境检查：覆盖聊天工具闭环、收藏、通话记录、MCP 会话与部分 SSE 数据、已停止请求不执行工具、备份转换、导入回滚，以及 MCP 语音标签、标题与播放结束。真实服务商 CORS、设备麦克风与手机布局仍需实际设备验收。


## Seed 25 · 统一外观

- 首页「外观」按钮与聊天「外观」入口打开同一套设置。`theme.js` 是唯一配置与明暗状态管理者，`theme.css` 是统一外观层，组件文件保留布局。移除聊天与语音原有的独立日间调色覆盖。
- 精简为青苹果、雾薄荷、樱雾、青墨四套配色；支持浅色、深色与系统模式。首页昼夜按钮同步到同一设置。明暗两侧可独立自定义强调色、背景和双方气泡颜色；气泡文字按底色自动选择黑白对比色。
- 壁纸支持 HTTPS URL 或相册图片，在本机缩放压缩；选择聊天或全局使用，提供对齐、遮罩与聊天滚动选项。换配色不会清除壁纸或阅读偏好。
- 气泡提供圆润、方角、线框和玻璃开关；字体提供系统与衬线，支持字号、间距、行距与减少动画。
- 外观独立导入导出，也包含在完整备份里。可从旧 `AevrenXYBackup` 迁移配色、壁纸、阅读与玻璃偏好；不迁移旧版 CSS 补丁或小猫/小熊装饰。
- 新配置只保存在 `yanya.xuanjing.theme.v1`；保留旧砚屿数据，旧仓库不改动。

新增检查：`node tests/theme.cjs`。覆盖系统明暗响应、配色切换不丢壁纸/字号、数值边界、URL 校验、旧版转换、文字对比色选择和存储失败时的一致性；已接入 Pages 发布前检查。真实手机视觉验收仍待进行。
